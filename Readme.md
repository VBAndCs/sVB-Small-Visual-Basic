**Sahla** is a native Basic dialect written directly with Small Visual Basic. It empowers young children to take their very first steps into coding by writing logic in their mother tongue!

* **Easy Customization:** You can easily localize Sahla into your native language by translating its keywords, giving kids an intuitive, barrier-free entry point into logical thinking and programming concepts before transitioning to standard sVB.

## Why Choose sVB Over Python for Beginners?

| Feature | Small Visual Basic (sVB) | Python |
| :--- | :--- | :--- |
| **GUI & Visual Design** | Built-in Drag-and-Drop Form Designer | Requires complex third-party GUI setups (e.g., Tkinter, PyQt) |
| **Case Sensitivity** | **Case-insensitive** (Editor auto-fixes casing) | Case-sensitive (`True`/`False` require capital letters) |
| **Array Indexing** | **1-based by default** (Natural for kids/beginners) | 0-based indexing |
| **Block Structure** | Clear explicit blocks (`EndIf`, `EndSub`, `Next`) | Indentation-sensitive (Miscounted spaces cause silent logic bugs) |
| **Type Conversion** | Automatic dynamic type management | Requires explicit type casting (e.g., `int()`, `str()`) |
| **Loop Syntax** | Simple: `For I = 1 To 5 ... Next` | Exclusive ranges: `for i in range(1, 6):` |
| **Bridge to Professional Dev** | Direct pathway to **VB.NET**, **C#**, and **Visual Studio** | Multi-paradigm, requiring separate transition paths |

## ?Open Source & Contributions
The sVB source code is written in **VB.NET** (WPF targeting .NET Framework 4.5) and hosted open-source on [GitHub](https://github.com/VBAndCs/sVB-Small-Visual-Basic). You can open and build the solution in **Visual Studio 2019 or later**.

*(Note: Before building from source, copy the `Lib` and `Toolbar` folders from `SmallBasicIDE\SB.Lib` into both `SmallBasicIDE\bin\Debug` and `SmallBasicIDE\bin\Release` directories).*
